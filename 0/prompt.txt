Verify these issues exist and fix them:

Bug 1:
In `Printf()`, the mutex is released before checking if `logger` is nil and calling `Init()`. This allows multiple concurrent goroutines to enter the unguarded `Init()` call. While `Init()` has its own mutex to prevent multiple initializations, the race condition creates a window where concurrent log calls could miss initialization or fail to synchronize properly. After `Close()`, the logger is reset to stderr, but `Init()` would detect `logger != nil` on subsequent calls and skip initialization entirely, potentially logging to the wrong destination.
